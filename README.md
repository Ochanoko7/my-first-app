# SKYBOUND — ちいさな冒険

HTML・CSS・JavaScriptだけで作った、横スクロールアクションゲームのMVPです。ビルドツールや外部ライブラリは不要です。

## 遊び方

- `index.html` をブラウザーで開きます。
- `←` / `→` または `A` / `D` で移動、`Space` / `↑` / `W` でジャンプします。
- スマートフォンでは画面下の操作ボタンを使えます。
- 光るかけらを集めながら、トゲや谷を避けてゴールの旗を目指します。
- `リスタート` ボタンまたは `R` キーで最初から遊べます。

## ファイル構成

- `index.html` — ゲーム画面とUI
- `style.css` — レイアウトと見た目
- `script.js` — 操作、ゲーム進行、描画
